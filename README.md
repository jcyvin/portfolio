# Olive Portfolio Hub

A polished Next.js portfolio landing page with dark olive styling and internal sample-site routes.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. In Vercel, choose Import Project and connect that GitHub repo.
3. Leave the framework preset as Next.js.
4. Use the defaults for Build Command and Output Directory.

Recommended settings:

- Framework Preset: Next.js
- Root Directory: `portfolio` if this repo is nested in a larger workspace
- Build Command: `npm run build`
- Install Command: `npm install`

The app is already configured for static hosting and standard Next.js deployment, so no extra Vercel config is required unless you want custom domains or environment variables.
